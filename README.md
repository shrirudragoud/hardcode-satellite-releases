# HardCode Satellite — downloads

The Satellite is the small desktop app that connects your Arduino/ESP board to the HardCode workspace at https://hard-code.in.

**Download:** see [Releases](../../releases). Pick the file for your OS:
- Windows: `ideaSim-Satellite-*-windows-amd64.zip`
- Linux: `ideaSim-Satellite-*-linux-amd64.tar.gz`

**Link it to your account:** run the app, choose "Link this computer..." (or run `satellite --pair`), then approve the code shown at https://hard-code.in/link. No passwords or keys to copy.

Verify downloads against `SHA256SUMS.txt` on each release. This repository only hosts release binaries.
